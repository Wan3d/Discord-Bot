Discord Bot with two basic games: **Guess the number** and **Hangman**.

**Guess the number**
In this game, the bot will generate a random number between 1 and 1000 and the user should guess which number the bot generated.
The user input will be received and compared each iteration, if the user guessed the number, the game will end and.
If the user input number is lower than the number generated, it will display a message saying that the number is too low.
If the user input number is high than the number generated, it will display a message saying that the number is too higher.

**Hangman**
For this game the bot will 'generate' a random word using a file with words.
The user have to guess the word after the Hangman is completed.

This bot also has some basic stuff as: show avatars, printer, replying hello.
